# Как менять контент

Все тексты, цены и статьи лежат в папке `content/`. Код трогать не нужно.

**Проще всего править через админку: `/admin/` на сайте, инструкция в [CMS.md](CMS.md).** Ниже — как устроены файлы, если правите их напрямую.

Сайт статический: **после любой правки нужна пересборка** (`npm run build` и перезапуск, или новый деплой; на Vercel/Netlify это происходит само после коммита в GitHub). Без пересборки меняются только переменные окружения сервера заявок (`LEAD_*`), и то после перезапуска.

Если в данных ошибка (нет обязательного поля, неверный slug), сборка остановится и напишет файл и поле. Это защита от публикации сломанных страниц.

## Статусы

| Где | Значение | Что происходит |
|---|---|---|
| `services/*.json`, `tours/*.json` → `status` | `demo` | видно только в режиме preview с плашкой «Пример» |
| | `confirmed` | опубликовано, попадает в sitemap и JSON-LD |
| | `hidden` | не показывается нигде |
| `articles/*/*.md` → `status` | `draft` / `published` | черновик виден только в preview |
| `site.json` → поле `confirmed` | `false` / `true` | неподтверждённый факт не показывается в production и не попадает в разметку |

## Добавить тур

1. Скопируйте `content/tours/shymbulak-first-snowboard-day.json` в новый файл, например `content/tours/ak-bulak-weekend.json`.
2. `slug` — латиница, цифры и дефисы, совпадает с адресом: `/ru/tours/ak-bulak-weekend/`.
3. Заполните поля. Текст на двух языках: `{ "ru": "…", "en": "…" }`. Если английского нет, уберите `en`: тур не появится в EN-версии, и hreflang не будет ссылаться на несуществующую страницу.
4. Поля с неизвестным значением оставьте `"value": null` и опишите в `"todo"`, что нужно узнать.
5. Цена: `"price": { "amount": 45000, "currency": "KZT", "unit": "person" }` (`unit`: `person` или `group`). Пока `amount` = null, на сайте «По запросу».
6. `availability` всегда `"request"`, пока не подключена система бронирования. Сайт не обещает свободные места.
7. `getYourGuideUrl` — необязательная ссылка на страницу на GetYourGuide.
8. Фото: положите JPG в `public/images/`, добавьте запись в `content/media.json` (src, width, height, alt на RU/EN) и укажите id в `images`.
9. Когда владелец подтвердил данные, поставьте `"status": "confirmed"`.

## Изменить цену

Откройте файл тура и поменяйте `price.amount`. Пересоберите сайт.

## Опубликовать статью

1. Создайте `content/articles/ru/<slug>.md`. Перевод на английский — файл **с тем же именем** в `content/articles/en/`: так сайт свяжет языковые версии.
2. В шапке (frontmatter) заполните: `title`, `description` (для поисковиков, до ~160 символов), `category` (ключ из `categories.json`), `cover` (id фото), `answer` (короткий ответ на главный вопрос, 2–4 предложения), `published`, `updated` (дата фактического обновления), `author`, `reviewer` (если есть эксперт), `relatedServices`, `relatedTours`, `relatedArticles`, `sources` (ссылка и дата проверки `checked`).
3. Пишите в Markdown. Заголовки `##` и `###` автоматически попадут в оглавление.
4. `status: draft` → проверка в preview. `status: published` → публикация.

## Сменить slug

Переименуйте файл и `slug`, затем добавьте в `content/redirects.json`:

```json
[{ "source": "/ru/tours/old-slug/", "destination": "/ru/tours/new-slug/" }]
```

Для каждого языка отдельная строка. Это постоянный редирект (308), поисковики перенесут сигналы на новый адрес.

## Контакты и факты о бренде

`content/site.json`. Когда владелец подтвердит, например, телефон: впишите `value` и поставьте `"confirmed": true`. WhatsApp-кнопка появляется, только когда задан `contacts.whatsapp.value`.

## Команда

Добавьте людей в `site.json → team` (имя, роль, био на RU/EN, список подтверждённых квалификаций). Страница `/team/` и пункт меню появятся автоматически.

## Казахский язык

В `src/i18n/config.ts` поставьте `kk.published: true` только когда есть проверенный перевод интерфейса (`src/i18n/dictionaries.ts`) и нужные страницы с полями `kk`. Пустые переводы не публикуем.

## Будущая CMS

Если владелец захочет редактировать через веб-интерфейс, к этой структуре подключается Git-CMS (например, Decap CMS или TinaCMS) без переделки страниц: они читают те же файлы.
